# SR-gripper visual meshes

These five STL files were copied unchanged from the commissioned reference
`stacking-tabletop/assets/sr_gripper/meshes/visual`. The active SR-gripper URDF
references the body, left/right arms, and left/right tips. Apply the visual
origins from that URDF: tip visual origins differ from their DSF collision
origins. The collision assets are separate and remain the solver inputs.
